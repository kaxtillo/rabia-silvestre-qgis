# Guía de Instalación

## Opción 1: Instalación rápida

1. Abrir QGIS.
2. Ir a Procesos → Caja de Herramientas.
3. Clic en el ícono de Python → "Añadir script desde archivo...".
4. Seleccionar `scripts/Epi_ROS.py`.

## Opción 2: Instalación permanente

Copiar el script a la carpeta de scripts del perfil de QGIS.
